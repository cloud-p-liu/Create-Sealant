# Security policy

This project is experimental. The current main branch is the maintenance target; there is no supported historical-release matrix or promised response time.

Do not post credentials, private worlds, or exploit details in a public issue. For a suspected vulnerability, use [this repository's enabled private vulnerability reporting](https://github.com/cloud-p-liu/Create-Sealant/security/advisories/new). For platform issues, use GitHub's platform security reporting channels. Include affected versions, impact, a minimal reproduction, and relevant sanitized logs.

Ordinary gameplay bugs, numerical instability, and performance reports without a security impact belong in public issues with sensitive data removed. Server-side permission validation, reset target checks, and untrusted network input are security-sensitive; client button state is not authorization.

Maintainers should acknowledge reports when able, coordinate a fix and validation, avoid publishing exploit details before mitigation, and credit reporters with their consent. No bounty or disclosure deadline is promised.
