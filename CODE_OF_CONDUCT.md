# Code of Conduct

Treat participants with respect regardless of background, identity, experience, or opinion. Give specific technical feedback, welcome questions, credit others' work, and distinguish evidence from assumptions. Disagreement is expected; harassment is not.

Do not threaten, insult, discriminate, sexually harass, dox, impersonate, or repeatedly disrupt others. Do not publish private information or continue unwanted contact. These rules apply to project issues, pull requests, discussions, reviews, and other spaces administered by maintainers.

Maintainers may edit/remove harmful content, request a change in behavior, or temporarily/permanently restrict participation. Use proportionate responses, explain the rule and expected behavior where safe, and protect reporter privacy. Maintainers are accountable to the same rules.

Report problems privately through a maintainer's publicly offered contact channel or GitHub's platform abuse-reporting tools. The current maintainer is listed in GOVERNANCE. Do not publish sensitive allegations in an issue. A maintainer involved in a report must recuse; seek an independent reviewer when necessary. Appeals may request review by an uninvolved maintainer or mutually acceptable independent reviewer. Keep sensitive case details private while recording policy-level outcomes when safe.

This is an original project conduct policy, distributed with the project under MIT.
